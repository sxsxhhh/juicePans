这是什么？
  本机运行的网盘资源搜索小站，打开浏览器就能搜。
  只搜索、只展示，不会登录你的网盘，也不会自动转存。
  结果来自公开检索，链接可能失效，请自行判断后再使用。

────────────────────────────────────────
一、开始前准备（只需做一次）
────────────────────────────────────────

1. 安装 Python 3.10 或更新版本
   官网：https://www.python.org/downloads/
2. 安装时务必勾选：
   □ Add python.exe to PATH
3. 装完后打开「命令提示符」输入下面这一行，能看到版本号就说明 OK：
   python --version
   （例如：Python 3.13.12）

────────────────────────────────────────
二、怎么启动（Windows）
────────────────────────────────────────

1. 解压绿色包后，进入文件夹 juicePans
2. 双击  start.bat
3. 会弹出一个黑色窗口，里面写着地址
   http://127.0.0.1:8765/
4. 约 2 秒后浏览器会自动打开搜索页
   若没有自动打开，请自己在浏览器地址栏输入上面的地址

重要：
  · 黑窗口不要关 —— 关掉就等于停止服务
  · 用完后直接关闭黑窗口即可

────────────────────────────────────────
三、页面上怎么搜
────────────────────────────────────────

1. 在搜索框输入片名 / 关键词，回车或点搜索
2. 上方 Tab 可切换：综合、夸克、百度、阿里、123 等
3. 引擎默认「盘搜 / 小云 / 海搜」，一般不用改
4. 结果会标「公开检索（未核验）」—— 点进去前请自行确认链接是否有效
5. 破解、色情、赌博等违规词会被拒绝搜索

────────────────────────────────────────
四、常见问题
────────────────────────────────────────

【双击 start.bat 黑窗口一闪就关】
  · 多半是没装 Python，或没勾选 Add to PATH
  · 请按「一、开始前准备」重装 Python 后再试
  · 也可在 juicePans 文件夹空白处按住 Shift 右键 →
    「在此处打开 PowerShell 窗口」，输入：
    python server.py
    看具体报错文字

【浏览器打不开 / 打不开页面】
  · 先确认黑窗口还在、里面没有报错
  · 手动访问：http://127.0.0.1:8765/
  · 若提示端口被占用，可关掉旧的黑窗口再开一次；
    或在启动前设置换端口（高级）：
    set JUICEPANS_PORT=8766
    然后再双击 start.bat（需在同一命令行环境里设置）

【提示找不到 python】
  · 重新安装 Python，勾选 Add python.exe to PATH
  · 或安装「Python Launcher」，本脚本也会尝试用 py -3

【能打开页面但搜不到结果】
  · 换个关键词、换「夸克」等 Tab 再试
  · 网络需能访问外网公开检索源
  · 部分来源不稳定属正常，可稍后重试

────────────────────────────────────────
五、文件夹里有什么
────────────────────────────────────────

  start.bat          ← 双击这个启动（Windows）
  start.sh           ← Linux / macOS 启动脚本
  server.py          ← 网站服务程序
  search_core.py     ← 搜索核心
  static/            ← 网页界面
  使用说明.txt       ← 本文件（给新手看）
  README_zh.md       ← 稍详细的说明（含 API）
  docs/              ← 调研笔记等（可忽略）
