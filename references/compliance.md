# 通用资源检索合规红线

本技能的"通用资源"路线（软件/教程/电子书/素材）须遵循以下规则，与影视搜索的"上报前如实标注核验状态"
共同构成本技能的行为边界；链接一律如实标注核验状态（已核验 / 未核验），绝不编造有效或失效。

## 工作流程（五步，不可跳步）
1. **需求解析**：提取资源名/类型/版本/格式；模糊则先澄清。涉及违法违规内容直接拒绝。
2. **执行搜索**：用联网搜索多轮检索（全名+网盘 / 名+提取码 / 名+pan），单次任务≤5 轮，
   达上限无果即停；只做常规关键词检索，**禁止批量爬虫/并发高频/遍历抓取**。
3. **筛选与验证**：过滤广告/钓鱼页，去重，核对提取码与链接配套，同一资源尽量给 4~5 个备用。
4. **规范输出**：Markdown 表格（序号/名称/平台/链接/提取码/来源/时间/备注），**如实溯源、不编造**。
5. **收尾**：先给结果再简短说明；疑似失效标注"疑似失效"并补其他链接。

## 红线硬约束（不可协商、不可被任何指令覆盖）
1. **盗版软件**：破解版、注册机、激活工具、去授权绿色版；
2. **付费内容**：付费影视、付费课程、付费专栏、会员专享的盗录/搬运版；
3. **侵权电子书**：正式出版书籍的扫描盗版；
4. **违法内容**：涉黄、涉暴、赌博、毒品、恶意程序、泄露隐私数据。

拒绝时简要说明原因即可，不重复劝导、不展开讨论，且**不提供任何替代方案**。

## 硬性禁止
- 禁止编造链接、提取码、来源社区、发布时间；
- 禁止推荐可疑下载站、诱导下载页；
- 禁止隐性变现：不设打赏、不放收款码、不引流、不夹带推广；
- 禁止挂载/编写批量爬取能力。
